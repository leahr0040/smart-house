## Phase Goal

**As an** authenticated user, **I want to** create, view, update, and soft-delete my own houses via REST, **so that** I manage the top of my home hierarchy and no other user can reach my houses.

<objective>
Deliver the full House CRUD vertical slice end-to-end: TypeBox-validated routes → ownership-embedded service → cascade soft-delete → multi-tenancy (404-not-403) and auth (401) enforcement, with the DB-touching test suite. This is the reference slice the Room and Device slices mirror.

Purpose: Houses are the root of the ownership hierarchy; every room and device is scoped under a house. Getting the ownership query pattern, the cascade transaction, and the public_id-only response construction right here sets the template for the other two slices.
Output: `src/routes/houses/{index,schemas}.ts`, `src/services/house.ts`, `src/test/routes/houses.test.ts`.
Sequence: follows CLAUDE.md structure-first → tests-red → implement (three tasks, three atomic commits).
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-2-H01 | Information Disclosure / Elevation of Privilege | GET/PATCH/DELETE /houses/:housePublicId (IDOR / BOLA) | high | mitigate | Ownership-embedded where:{publicId,userId}; cross-tenant miss returns 404 not 403 (test asserts) — HOUSE-05/TEST-01 |
| T-2-H02 | Spoofing | All /houses routes without JWT | high | mitigate | preHandler: fastify.authenticate on every route; 401 asserted for each (TEST-08) |
| T-2-H03 | Tampering | PATCH mass assignment (userId/deletedAt) | medium | mitigate | TypeBox body declares only name/address + additionalProperties:false; service destructures name/address explicitly |
| T-2-H04 | Information Disclosure | Internal BigInt id leakage in responses | medium | mitigate | Responses constructed field-by-field with publicId only; no raw-row spread; test asserts no `id` key |
| T-2-H05 | Tampering | Non-atomic cascade leaving orphan live rooms/devices | high | mitigate | Cascade runs in one $transaction using direct updateMany (never the delete-interception escape, Pitfall 1); cascade test asserts children soft-deleted |
