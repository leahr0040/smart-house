## Phase Goal

**As an** authenticated user, **I want to** create, view, update, and soft-delete rooms inside houses I own, **so that** I can organize my home into rooms without any other user reaching them.

<objective>
Deliver the full Room CRUD vertical slice end-to-end: nested creation under a parent house (with parent-ownership verification), TypeBox-validated routes → ownership-embedded service → room→devices cascade soft-delete → multi-tenancy (404) and auth (401), with the DB-touching test suite.

Purpose: Rooms sit between houses and devices. The distinctive risk here is nested-parent ownership bypass — a user must not create a room under someone else's house. This slice locks that boundary.
Output: `src/routes/rooms/{index,schemas}.ts`, `src/services/room.ts`, `src/test/routes/rooms.test.ts`.
Sequence: CLAUDE.md structure-first → tests-red → implement (three tasks, three atomic commits).
</objective>
